# Support

TimeFarm 0.1.x is a beta preview. Use the repository issue tracker for
reproducible non-sensitive bugs and feature requests. Include the application
version, Windows version, expected behavior, actual behavior, and minimal steps
to reproduce.

Use the private process in `SECURITY.md` for vulnerabilities. Do not attach
tokens, credentials, private work history, payment data, or an unredacted local
database to a public issue.
